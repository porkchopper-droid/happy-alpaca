# Happy Alpaca Farm 🦙

## 📌 Overview
The **Happy Alpaca Farm** is a fun, beginner-friendly project built with **HTML, CSS, and JavaScript**, designed to showcase an interactive farm experience. Visitors can explore alpacas, book tours, shop for fresh products, and enjoy a countryside stay.

## 🛠️ Technologies Used
- **HTML & CSS** 🎨 (Responsive design)
- **JavaScript** ✨ (Interactive elements)
- **Flexbox & Grid** 📏 (Layout structure)
